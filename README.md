# UnifiedCXR-A-Multi-Disease-Chest-X-Ray-AI-Diagnostic-System
UnifiedCXR is a deep learning–based chest X-ray diagnostic system developed at IIT Kharagpur for detecting Tuberculosis, Pneumonia, and Cardiomegaly. It uses VGG19, VGG16, and EfficientNet-B0 with transfer learning and ensemble modeling on 16,000+ X-ray images for robust and accurate diagnosis.
